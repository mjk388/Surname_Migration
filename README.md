# Surname_Migration
This repository contains functions used in the study on quantifying migration in Malopolska between Golden Age and Great War.
It contains 3 algorithms which aim to identify region of origin of the given surname. 

Input data are the featched birth records from multiple free online sources: 
- Genealodzy.pl
- FamilySearch
- Wikipedia
- GenezaNazwisk.pl
- Generic Google search results

Algorithm 1
It aims to identify the region where the oldest record has been found and to provide information on the regions with most occurences of the given surname. 
In addition it gives a probability score of surname originating from the region of oldest record and probability of surname originating from the region with most occurences. The probability is based on occurences.
